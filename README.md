# ✿ My 2027 Flower Calendar ✿

A beautiful, pink and purple themed HTML calendar for the year 2027.
Built with pure HTML and CSS — no JavaScript used.

## 🌷 Features

- 12 month calendar grid displayed in 3 columns
- Aesthetic flower images for each month
- Saturdays and Sundays highlighted in pink
- South African public holidays marked with a purple gradient
- Full public holidays reference table with descriptions
- Cute Google Fonts — Playfair Display and Quicksand
- Soft pink and purple colour theme throughout
- Fully responsive and clean layout

## 🌸 Technologies Used

- HTML5
- CSS3 (CSS Grid, Google Fonts, linear gradients)

## 🌺 South African Public Holidays Included

- New Year's Day — 1 January
- Human Rights Day — 21 March
- Good Friday — 26 March
- Family Day — 29 March
- Freedom Day — 27 April
- Workers Day — 1 May
- Youth Day — 16 June
- National Women's Day — 9 August
- Heritage Day — 24 September
- Day of Reconciliation — 16 December
- Christmas Day — 25 December
- Day of Goodwill — 26 December

## 💐 How to View

1. Download or clone this repository
2. Open the `index.html` file in any web browser
3. No installation needed!
